# Install Picture Logic

On a Kindle started with Primitive Launcher, open **Store**, find **Picture Logic**, and tap **Get**. Launch the game from your app grid.

For local testing on an ARMHF Kindle, verify the SHA-256 of the release archive and extract it. Copy the `picturelogic/` folder to the Kindle drive root and `documents/PictureLogic.sh` into the existing Kindle `documents/` folder. Eject the drive and open **Picture Logic** in Launcher.

The game saves progress in `picturelogic/picturelogic.json`. Back up that file before removing the game folder manually.
